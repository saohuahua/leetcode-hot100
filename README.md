# LeetCode Hot100 算法基础与解题方法

本教材以 LeetCode Hot100 为范围，系统说明常用数据结构、算法设计方法与 TypeScript 实现。解题分析按**问题定义 → 朴素方法 → 计算瓶颈 → 状态设计 → 正确性依据 → 实现**展开，重点解释方法的来源及其成立条件。

适用读者为具备 TypeScript 编程经验、需要系统补充算法基础的前端开发者。学习目标分为解法分析与独立实现两层：首先能够脱离代码说明状态含义、操作步骤与正确性依据，其次完成实现与验证。内容重心按基础约 40%、思路约 40%、代码约 20% 组织；比例用于约束讲解重点，不作为逐篇字数指标。

2. [复杂度与数据结构](chapters/00-算法入门与TypeScript基础/02-复杂度与数据结构.md)：操作成本、增长阶与结构选择。
3. [哈希基础](chapters/01-哈希/README.md)及[两数之和](chapters/01-哈希/0001-两数之和.md)：从重复查找推导索引查询的完整示例。
4. [TypeScript 运行时与递归](chapters/00-算法入门与TypeScript基础/03-TypeScript运行时与递归.md)：引用语义、数值边界与调用栈。

解法复述与编码能力分别检查。复述应包含操作对象、维护信息、更新依据、终止条件和复杂度，仅给出算法名称不构成完整解释。

## 学习与复习流程

- 问题分析：明确输入、输出与约束，以小规模实例建立朴素方案。
- 方法推导：定位重复计算或无效搜索，定义所需状态及更新规则。
- 过程验证：逐步记录状态变化，核对边界处理、终止条件与正确性依据。
- 解法复述：在不依赖实现代码的情况下说明完整方案，与折叠区内的参考概述对照。
- 编码验证：独立完成 TS 实现，使用样例、合法边界与反例检查结果。
- 迁移复习：分析条件变化对原方法的影响，再通过混合题检验独立选择方法的能力。

分层提示分别提供观察方向、所需信息与步骤组织，可按当前分析进度查阅。对于难以仅靠文字追踪的指针、状态和依赖关系，正文配有 SVG 图示；图示与状态表共同说明具体执行过程。

全部图示及其对应推导见 [算法图示索引](FIGURES.md)。

学习状态在 [学习进度表](PROGRESS.md) 中按能力项记录，与教材交付状态分别维护。

## 代码运行

需要 Node.js 22 及 npm。安装依赖后执行以下命令，不需要 build。

```sh
npm install
npm run typecheck
npm test
npm run check:docs
```

单独运行一个分类的测试，例如哈希：

```sh
npx tsx --test tests/01.test.ts
```

本地解答用命名导出，便于测试。提交力扣时移除 `export` 和本地类型导入；链表和树题使用题目提供的节点类型，随机链表题将 `RandomNode` 改为平台的 `Node`。第 295 题依赖 [BinaryHeap](solutions/13/heap.ts)，提交时把这个辅助类复制到入口代码前，不能只删除导入；第 215 题利用官方固定值域计数，第 347 题采用线性频次桶，均保留堆作为对照思路。函数与类的公共方法保持题目入口约定。测试辅助构造函数不提交。
