# 逐题结构调整审阅记录

## 范围与来源

本轮核对了 Hot100 清单中的 100 份逐题文档。题面事实来自清单中各题的力扣中文题面，逐项读取示例、约束和进阶要求。题面说明沿用原有原创讲解并重组；示例仅保留输入输出，不复制官方解释段落。可直接取得的 19 份官方题解用于对照推导，其他题以题面、提示和原有已审阅的推导为基础。两数之和、最大子数组和及 LRU 缓存附有可直接访问的官方题解链接。

## 检查结果

- `npm run check:docs` 通过，覆盖 100 题归档、章节顺序、示例输入输出、约束、代码围栏同步及本地链接
- 临时来源对照检查通过，100 题的官方示例数量与文档一致
- `git diff --check` 没有空白错误，仅显示工作区的 LF 与 CRLF 提示
- 未修改 `solutions` 或 `tests`，本轮不执行 build

自动检查只能验证结构和可比对的题面事实，不能证明每段推导的教学效果。本轮人工重点复看了哈希、窗口、链表、树、回溯、二分、栈、动态规划和技巧中的代表题；其余题的原有推导主要做结构搬移，仍应在真实学习反馈中继续检查理解难点。
