## 已发现并处理的主要问题

- 最小覆盖子串的临时代码标记与示例中的CODE撞名，导致代码插错位置。修正生成定位，并增加实现章节位置和裸占位符检查。
- 二分复习反例的中点并不满足文字条件，更换为能真实触发相等歧义的数组。
- 第215题原堆主解未满足官方线性时间要求，改用官方固定值域计数选择，明确O(n+U)与U固定的前提。
- 第347题原堆主解未覆盖官方进阶时间目标，改用完整的线性频次桶推导与实现。
- 最长公共子序列的同尾字符证明遗漏顺序前提，补齐末字符反证、合法移位和上下界。
- 第124 543 236题原递归实现会在合法深链输入下触发调用栈溢出，修订为显式遍历并加入题目规模上限回归。各项最终复核状态见对应记录。
- 07与08章节的通用口述检查替换为29份逐题专属问题，再由另一位agent逐项核对与主解的一致性。

交付时移除了临时写作生成脚本与批量修订脚本，避免旧稿生成覆盖已经人工复核的正文。审阅表中对这些脚本的引用是缺陷发生与修复时的历史位置。正式文档和源码作为维护入口，保留的检查、同步、索引与图示工具见 [工具说明](../scripts/README.md)。
