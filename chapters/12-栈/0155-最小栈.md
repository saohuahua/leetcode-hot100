# 0155 最小栈

普通栈能很快压入和弹出，但想随时知道当前最小值，不能每次从头扫描。关键是弹出以后，如何找回此前的最小值。

相关基础：[本章基础](README.md)。[力扣原题](https://leetcode.cn/problems/min-stack/)。

## 问题定义

实现MinStack，支持push、pop、top、getMin，要求这些操作在算法模型下常数时间。top返回顶值，getMin返回整个当前栈的最小值。题目保证查询和删除时栈非空，因此不需要设计空栈业务返回值。

## 朴素方法与复杂度

先用数组实现push与pop。求最小值时扫描全部元素，这一定正确，但一次getMin要O(n)。换成只维护一个最小变量似乎可行：压入更小元素时更新。然而弹出这个最小元素后，旧变量不知道剩余元素中的最小者。

## 优化依据

删除当前最小元素后，需要恢复剩余前缀的最小值。每次压入一个新值，新的整体最小值只可能是它或此前最小值。把这个结论随这一层一起保存，弹出时旧记录仍然存在，就不必重新扫描。

## 算法推导

每个栈条目保存value和min，min表示从栈底到当前条目这一整段的最小值。初始为空。压入x时，若无旧顶，min就是x；否则min为x和旧顶min的较小值。取顶值读取value，取最小值读取顶项min。弹出整个条目即可同时恢复前一层的最小记录。

这个记录不是全局最小值的独立副本，而是对应一个特定前缀。首次压入时只有一个元素，因此该元素就是当前最小值。假设旧顶记录确实是旧元素最小值，新增元素只有x，比较二者就得到新整体最小。删除后剩下的恰好是此前前缀，旧记录不需要修改。

重复最小值也无需特殊分支。例如压入两个1，两层各自记录1，弹出一层后另一层仍保留1。这比只在严格变小时维护历史更不容易漏掉等值情况。

## 执行过程示例

依次压入3、1、2，再弹出两次。

| 操作 | 顶项中的值与前缀最小值 | getMin |
| --- | --- | --- |
| push 3 | 3 与3 | 3 |
| push 1 | 1 与1 | 1 |
| push 2 | 2 与1 | 1 |
| pop | 恢复1与1 | 1 |
| pop | 恢复3与3 | 3 |

最后恢复3并不是临时扫描得到的，而是第一层一直保留的记录。

## 解法复述与检查

每层min覆盖哪段元素？弹出后为什么不重新计算？连续两个相同最小值会不会丢失记录？

<details><summary>算法概述</summary>

使每层同时保存该元素和截至这一层的最小值。压入时只比较新值与旧顶保存的最小值，弹出时整层移除，前一层自然恢复。于是getMin只读顶层记录，重复最小值也由各层独立保存。

</details>

## TypeScript 实现

源码见 [0155.ts](../../solutions/12/0155.ts)。

```ts
export class MinStack {
  private readonly stack: Array<{ value: number; min: number }> = []

  push(val: number): void {
    const previous = this.stack[this.stack.length - 1]
    // 每层保留对应前缀的最小值以支持弹出后的恢复
    this.stack.push({ value: val, min: previous ? Math.min(val, previous.min) : val })
  }

  pop(): void {
    this.stack.pop()
  }

  top(): number {
    return this.stack[this.stack.length - 1].value
  }

  getMin(): number {
    return this.stack[this.stack.length - 1].min
  }
}
```

## 复杂度与边界

算法层面每次只读写固定个数的记录，操作O(1)，保存n个元素用O(n)空间。实际JS动态数组push扩容可能产生单次额外开销，通常按均摊O(1)分析；这与哈希平均复杂度不是同一概念。不修改调用方对象，数值直接保存。

## 变式分析与错误反例

若还要同时查询最大值，每层再保存该前缀最大值，压入时多做一次比较即可。若需要查询任意第k小，固定几个前缀统计量已经不够，不能只增加一个变量就完成任意排名查询。

错误反例：只保留全局min，依次push 3、push 1、pop后仍返回1，而真实最小值是3。另一个易错点是辅助最小栈只在严格小于时入栈，却在等于时弹出，重复1会使记录提前消失。
