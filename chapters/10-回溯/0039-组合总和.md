# 0039 组合总和

相关基础：[本章基础](README.md)。题目来源：[力扣 39](https://leetcode.cn/problems/combination-sum/)。

## 问题定义

给互不相同的正整数候选数组和正目标值，每个候选可以无限次使用，返回所有和等于目标的组合。组合不计顺序，[2,2,3] 与 [3,2,2] 是同一答案。输出具体组合而不是数量，因此不能只用一个可达布尔值替代完整搜索。

## 朴素方法与复杂度

候选[2,3,6,7]凑7，可以先尝试拿2，剩5再拿2剩3，再拿3正好；也可以一开始拿7。如果任意顺序尝试每个数，同一组合会以223、232、322多次出现。这里有两件事要同时解决：允许同值重复使用，又不允许组合排列顺序制造重复答案。

## 需要的信息

先把候选复制并按数值递增排序，维护path、remaining和start。path是已选数字，remaining是目标减当前和，start表示下一次最小允许候选下标。限制下标不下降，使每个组合只按非递减顺序生成；递归时继续允许当前i，而不是i+1，表达可以重复使用当前数。

排序并不是为了改变组合意义，而是让“当前数已大于剩余值”时，后面的数也一定过大，从而可以结束本层循环。复制再排序让函数不修改用户输入，符合这里教材主解的输入约定。

## 算法推导

剩余值为零时复制path加入答案，结束该分支。否则从start开始枚举候选。若当前数大于remaining，直接break；否则加入当前数，递归visit(i,remaining-value)，返回后弹出。

为什么剪枝安全？候选全为正，超额以后追加任何数都无法降低总和；排序确保更后数只会更大。为什么会结束？每次加入至少一个正整数，remaining严格下降，到零或无可用候选后停止。若允许零或负数，这个终止与剪枝理由会失效，不能继续直接使用该写法。

每个组合都能唯一排成非递减顺序，其序列会沿着不下降的下标路径被枚举。反过来每个输出路径都达到目标且没有改变顺序，因此合法。同值重复来自同一个i的连续多次选择，而不是多个不同排列顺序，保证完整且不重复。

## 执行过程示例

候选[2,3]，目标5。

| 当前路径 | 剩余 | 动作与理由 |
| --- | --- | --- |
| [] | 5 | 先选2 |
| [2] | 3 | 再选2尝试复用 |
| [2,2] | 1 | 候选2已经过大 返回撤销 |
| [2] | 3 | 改选3 |
| [2,3] | 0 | 复制答案 再逐层撤销 |
| [3] | 2 | 起点只能是3而3过大 不回头选2 |

最后只有[2,3]。最后一行虽然没有返回找2，却没有漏解，因为那会重新生成前面已经得到的同一组合。

## 解法复述与检查

同一个候选为什么可以复用？为什么不允许回到更小下标？为什么剩余不足可以直接break？

<details><summary>算法概述</summary>按非递减候选顺序建立组合，用起点限制下一次选择。选了下标i以后仍从i继续，允许重复该数，但不回到更小下标避免顺序重复。正数让剩余不断减小，排序后遇到大于剩余的数即可停止。剩余为零复制当前组合。</details>

## 复杂度与边界

令D=floor(target/最小候选)，递归深度最多D。输出相关搜索是指数级，可用O(k^(D+1)+R·D)作宽松上界，加O(k log k)排序，k为候选数R为答案数；k=1时搜索为O(D)。辅助空间O(k+D)含排序副本、路径和栈，输出O(RD)。不修改输入。无解返回空数组，不能返回包含空路径。

## 变式分析与错误反例

若每个候选只用一次，递归起点应变成i+1；若输入还能有重复值，还需同层跳过等值候选。错误沿用子集的i+1会漏掉[2,2,3]。若目标为零且允许空组合，数学上应返回[[]]，但本题目标为正，不把这个扩展冒充官方边界。

## TypeScript 实现

本地使用命名导出供测试调用 提交力扣时按题目入口移除导出声明

```ts
export function combinationSum(candidates: number[], target: number): number[][] {
  const values = [...candidates].sort((a, b) => a - b)
  const result: number[][] = []
  const path: number[] = []
  const visit = (start: number, remaining: number): void => {
    if (remaining === 0) {
      result.push([...path])
      return
    }
    for (let i = start; i < values.length; i++) {
      // 后续数更大所以当前超额时整段均可排除
      if (values[i] > remaining) break
      path.push(values[i])
      // 保留当前下标以允许重复使用同一候选
      visit(i, remaining - values[i])
      path.pop()
    }
  }
  visit(0, target)
  return result
}
```
